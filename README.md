### :man_technologist: About Me

CS student at CU Boulder and Director of Technology for the CU Boulder Interfraternity Council, where I build the systems that run event ops and access control for 22 chapters and 2,500+ members.

- :bricks: Building **[FratDoor](https://github.com/grahamzemel/FratDoorWeb)**, a guest-management + check-in platform now running at 42 fraternities with 150,000+ processed check-ins.
- :ghost: Shipped **[TextCloaker](https://github.com/grahamzemel/TextCloakerWebsite)**, a bootstrapped AI-text SaaS + Chrome extension with 7,000+ users and 3.3M+ characters cloaked.
- :bug: Hunt bugs on HackerOne and build my own recon/pentest tooling, like **[WebHeckScanner](https://github.com/grahamzemel/WebHeckScanner)**.
- :package: Publish open-source infra, like **[offline-sync-engine](https://github.com/grahamzemel/offline-sync-engine)**, an offline-first sync/idempotency library on npm.
- :writing_hand: Write on [Medium](https://grahamzemel.medium.com/) and publish **[The Gray Area](https://thegrayarea.tech)**.
- :mailbox: Reach me through the contact form on [grahamzemel.com](https://grahamzemel.com/contact).

### :rocket: Featured Projects

| Project | What it does |
|---|---|
| **[FratDoor](https://github.com/grahamzemel/FratDoorWeb)** | Event-management platform for fraternity chapters — QR/ID check-in, whitelist/blacklist policy enforcement, Stripe/PayPal ticketing, and live ops dashboards. Adopted by 42 chapters, 300+ events, 150k+ check-ins. |
| **[IFC EventHub](https://github.com/grahamzemel/IFC_EventHub_Frontend)** | Event registration system for rush and chapter events with automated notifications, emergency-contact workflows, and centralized operational records for the IFC. |
| **[TextCloaker](https://github.com/grahamzemel/TextCloakerWebsite)** | Full-stack SaaS + Chrome extension that uses zero-width Unicode insertion and homoglyph substitution to preserve text readability while defeating AI-detector parsing. 7,000+ users, subscription billing, referral system, and live admin analytics. |
| **[offline-sync-engine](https://github.com/grahamzemel/offline-sync-engine)** | Zero-dependency npm package for offline-first mutation queues with idempotent server primitives — keeps check-in scanners working when venue WiFi dies. |
| **[WebHeckScanner](https://github.com/grahamzemel/WebHeckScanner)** | Bash-driven web vulnerability scanner orchestrating Nikto, Nuclei, Sqlmap, and recon tools like Gau/Httpx/Waybackurls for HackerOne-style pentesting. |
| **[Sentinel](https://github.com/grahamzemel/sentinel)** | Algorithmic trading engine in Python with aggressive/conservative strategies and a live dashboard for monitoring autonomous trades. |
| **[Quantum Chat](https://github.com/grahamzemel/QuantumChat)** | Chat app that encrypts messages using quantum mechanics principles instead of classical crypto. |
| **[Game Bank](https://github.com/grahamzemel/GameBank)** | Collaborative project exploring game economy/inventory mechanics, built with [Perrin Root](https://perrinroot.com). |

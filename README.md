## 👨‍💻 About Me

I'm a CS student at **CU Boulder** and **Director of Technology** for the CU Boulder Interfraternity Council, where I build and run the systems behind event ops and access control for **22 chapters and 2,500+ members**. Outside of class I ship products end-to-end — frontend, backend, infra, and the boring ops stuff that makes them actually work in production.

```yaml
role: Director of Technology @ CU Boulder IFC
studying: B.A. Computer Science (Minor: Philosophy) @ University of Colorado Boulder
currently_building: FratDoor — campus-wide event & access-control platform
side_quests: bug bounty hunting on HackerOne, open-source infra, algo trading
reach_me: grahamzemel.com/contact
```

- 🧱 **Building [FratDoor](https://github.com/grahamzemel/FratDoorWeb)** — a guest-management + check-in platform live at **42 fraternities**, processing **150,000+ check-ins** across 300+ events.
- 👻 **Shipped [TextCloaker](https://github.com/grahamzemel/TextCloakerWebsite)** — a bootstrapped AI-text SaaS + Chrome extension with **7,000+ users** and **3.3M+ characters cloaked**.
- 🐛 **Hunt bugs on HackerOne** and build my own recon/pentest tooling, like [WebHeckScanner](https://github.com/grahamzemel/WebHeckScanner).
- 📦 **Publish open-source infra** — [offline-sync-engine](https://github.com/grahamzemel/offline-sync-engine), a zero-dependency offline-first sync/idempotency library on npm.
- ✍️ **Write** on [Medium](https://grahamzemel.medium.com/) and publish [The Gray Area](https://thegrayarea.tech).
- 📫 **Reach me** through the contact form on [grahamzemel.com](https://grahamzemel.com/contact).
